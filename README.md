# Aula 22/09: plataforma pixel art

Atividade da faculdade de set/2023. Publiquei anos depois (nov/2026) e não atualizei nada.

Plataforma em pixel art feito na aula de 22/09/2023. O personagem anda, pula, coleta itens (com contador), solta um poder que destrói inimigos e troca de cena no final. Esse projeto também estava salvo como `Aula_22_09.unitypackage`, com os mesmos scripts.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.15f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

## Créditos

Os sprites são dos pacotes Pixel Adventure 1 e 2D Pixel Art Platformer Biome (Plains), da Asset Store.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
